15. SCREENSHOTS (SYSTEM VISUAL DOCUMENTATION)

This chapter provides a comprehensive visual walkthrough of the CyberShield AI interface. Each screenshot is accompanied by a technical description of the UI components and the underlying logic they represent.


SCREEN 01: CYBERSHIELD AI - LOGIN GATEWAY
Description: The entry point of the system featuring a high-contrast dark mode aesthetic. The UI utilizes "Glassmorphism" effects with a backdrop blur for the login card. 
Technical Context: This view validates the session integrity through the Flask login manager. It displays the "Identity Verified" secure icon upon successful HASH check.

SCREEN 02: SYSTEM DASHBOARD OVERVIEW
Description: The primary monitoring hub. It showcases a grid-based layout summarizing "System Health," "Prediction Latency," and "Last Attack Detected."
Technical Context: Data is dynamically fetched via the /api/heartbeat endpoint to ensure the dashboard reflects the real-time state of the ML engine.

SCREEN 03: MANUAL PACKET PARAMETER INPUT FORM
Description: A sophisticated form where security analysts can manually enter network traffic metrics (e.g., Duration, Protocol, SRC Bytes). 
Technical Context: Every input field features client-side validation using JavaScript to prevent out-of-range numerical errors before the tensor is sent to the backend.

SCREEN 04: BATCH DATA INGESTION (CSV/PCAP UPLOAD)
Description: A drag-and-drop interface for uploading standardized datasets (NSL-KDD/CICIDS). 
Technical Context: The backend utilizes the Secure-Filename utility to sanitize the file path and initializes the Pandas ingestion pipeline upon upload completion.

SCREEN 05: INFERENCE ENGINE LOADING STATE
Description: A cinematic animation showing the Stacking Ensemble processing a large batch of packets. 
Technical Context: Represents the period where the pre-trained joblib model is mapping the input vector through the Random Forest forest.

SCREEN 06: INTRUSION DETECTION ALERT - CRITICAL (ATTACK)
Description: A high-visibility Red alert banner triggered when the model identifies a threat.
Technical Context: Displays the specific attack sub-class (e.g., "NEPTUNE - DOS") derived from the label mapping array.

SCREEN 07: SAFE TRAFFIC CONFIRMATION
Description: A calming Green confirmation screen for legitimate network requests.
Technical Context: Indicates a "Normal" classification with a probability score > 0.95.

SCREEN 08: EXPLAINABLE AI (SHAP) OUTPUT - BAR PLOT
Description: A complex bar chart showing how features like "Count" or "Serror_Rate" pushed the prediction.
Technical Context: Rendered directly from the Matplotlib output generated by the shap.summary_plot function.

SCREEN 09: HUMAN-READABLE XAI JUSTIFICATIONS
Description: A text-based breakdown of the SHAP values (e.g., "The attack was flagged due to 80% higher than average sync-errors").

SCREEN 10: GENERATIVE AI MITIGATION LOGIC
Description: An auto-generated code snippet (e.g., Python script or Bash command) to block the offending IP.
Technical Context: Maps the attack signature to a predefined mitigation matrix for immediate incident response.

SCREEN 11: RECOMMENDED INCIDENT RESPONSE STEPS
Description: A checklist of manual actions for the administrator (e.g., "Notify SOC," "Isolate Node 14").
Technical Context: Part of the holistic risk management layer of the platform.

SCREEN 12: STACKING ENSEMBLE ACCURACY OVERVIEW
Description: A performance gauge showing 98.4% accuracy and localized confusion matrices.
Technical Context: Validates the model integrity for academic reviewers using real-time test-set metrics.

SCREEN 13: HISTORICAL THREAT LOG
Description: A paginated list of previous scans and their results.
